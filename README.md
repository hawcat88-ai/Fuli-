这是手机/平板优先的真实 A 股行情测试版。

## 本阶段
只扫描 5 个板块：
- 半导体 512480

- 军工 512660

## 数据原则
- 行情：东方财富公开行情接口
- 日K：东方财富公开K线接口
- 不使用随机演示数据
- 行情失败会明确报错，不会伪造数据
